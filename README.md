## 👋 Hey, I'm Vijay

I'm actively moving toward **Forward Deployed Engineering** and **GenAI Engineering** — the intersection of real customer problems, working prototypes, and shipping things that hold up.

```
Understand the problem → Prototype → Integrate → Debug → Deploy → Iterate
```

What pulls me toward FDE specifically: it's the closest engineering role to the actual problem. You can't abstract your way out of a broken integration at 2am. That's the work I want to get better at.

Right now: finishing the Graph RAG assistant, deepening agent evaluation, and getting comfortable with Kubernetes past the basics.

## 🌟 Flagship Project

### 🕸️ Graph RAG Knowledge Assistant

A knowledge assistant that goes beyond flat vector search — it uses **Neo4j graph relationships** alongside **semantic embeddings** to understand how documents connect, not just what they say.

Built specifically to answer: *does adding graph structure actually improve retrieval quality, and when?*

```
PDF → Chunking → Embeddings → Graph Relationships → Retrieval → LLM → Grounded Answer
```

`FastAPI` · `Neo4j` · `Embeddings` · `Vector Search` · `RAG` · `LLM`

| Pattern | Key Question Explored |

| Simple Agent | How does a basic tool loop actually behave? |
| Tool-Using Agent | What does Pydantic structured output change? |

## ⚡ The Way I Work

<div align="center">

| | | |
|:---:|:---:|:---:|
| 🔍 | **Understand** | What is the *actual* problem — not the stated one |
| 🧪 | **Prototype** | Build the smallest thing that answers it |
| 🔗 | **Integrate** | Where assumptions meet reality |
| 🔧 | **Debug** | Where real learning happens |
| 🚀 | **Deploy** | Make it real — local doesn't count |
| 🗣️ | **Explain** | If you can't explain it, you don't own it |
| 🔁 | **Iterate** | What would you build differently now? |

</div>

<div align="center">

```
The gap between a working prototype and a working integration
is where most ideas die — and where I want to work.
```

</div>

> It's about building your way to one — and being honest about what broke along the way.
